# v0.1.3

Starshelf improves interaction reliability on the latest GitHub interface while polishing popup layout for longer repository names.

## Highlights

- **Reliable star click handling** — fixed the new GitHub UI edge case where clicking stars could fail to register inside the overlay.
- **Popup checkbox polish** — added a line-clamp style for checkbox labels so long repository names no longer overflow the settings layout.
- **Updated docs** — README and release assets refreshed to reflect the latest behavior and release details.

## Fixes

- Resolved star click detection failures on the newest GitHub UI updates.
