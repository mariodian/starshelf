# v0.1.4

Starshelf is more reliable when syncing your stars, regenerating a category, and opening repository links from the popup. Most of this release is internal cleanup.

## Highlights

- **Links stay in the popup** — search results and other links open in a new browser tab instead of replacing the popup.
- **Safer star sync** — a full sync keeps the original date you starred each repository, saves progress in pages, and reports errors instead of failing silently.
- **Steadier regenerate** — regenerating a category uses the repository Starshelf already saved, so it no longer depends on re-reading the GitHub page.

## Fixes

- Saving a repository no longer fails when optional details, such as a description or list, are missing.

## Notes

- This release is mostly internal cleanup. Behavior you already rely on should feel the same, aside from the reliability fixes above.
